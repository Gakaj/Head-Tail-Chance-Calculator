# Coin Flipping Simulator

**This is an educational python project created by an A Level Student interested in Computer Science**

Imagine you flip a coin 10 times, how many attempts until a 50/50 result? Now imagine you flip it 1000 times, again how many tries until after 1000 flips will the number of heads and tails equals. This program demonstrates and simulates this within the restrictions of a computers "random" bias.
